# cache-meter

Мод для Claude Code: размер контекста, срок жизни кэша промпта и лимиты подписки над полем ввода.

```
ctx ███▍░░░░░░░░░░░░░░░░ 170k/1M (17%) · кэш 1h: 42:10 · hit 98% · 5ч 23% до 14:30 · 7д 41% до пт 10:00
```

## Что умеет

**Полоса над промптом**, обновляется раз в секунду:
- `ctx` — сколько токенов уйдёт в следующий запрос. Полоска показывает долю окна модели, цвет — абсолютный размер: зелёный до 200k, жёлтый до 300k, оранжевый до 400k, дальше красный. Качество ответов падает задолго до заполнения окна в 1M, поэтому цвет считается не от процента.
- `кэш 1h: 42:10` — сколько осталось жить кэшу промпта. Отсчёт идёт от последнего запроса основного диалога: каждый запрос продлевает кэш. Когда срок выйдет, появится «истёк N мин назад» и сколько токенов следующий запрос запишет заново.
- `hit 98%` — какая доля последнего запроса пришла из кэша.
- `5ч`, `7д` — использованная доля 5-часового и недельного лимита подписки и время сброса.
- `агенты 2 (340k)` — пока работают субагенты: сколько их и сколько токенов они обработали.

**Под каждым ответом** — служебная строка, модель её не видит:
```
ответ: 14 запросов · кэш: чтение 1.8M / запись 35k · ввод 2k · вывод 6k · ≈190k вх.
```
`≈190k вх.` — цена ответа в токенах обычного ввода (чтение из кэша ×0.05, запись ×2, вывод ×5), чтобы сравнивать ответы между собой.

**Уведомления:**
- за 5 минут до истечения кэша — системное уведомление и toast;
- «кэш потерян», если таймер ещё жив, а запрос почти не попал в кэш, с вероятной причиной: смена модели, смена effort, изменился CLAUDE.md или инструменты;
- результат инструмента больше 15k токенов: «Read UserController.php добавил в контекст ~22k»;
- файл прочитан третий раз за сессию.

**Продление кэша.** `/keepalive` отправляет короткий запрос поверх всего диалога: префикс читается из кэша, и его срок начинается заново. В историю диалога запрос не попадает. Автопродление срабатывает само за 2 минуты до истечения, но только один раз: следующее станет доступно после вашего сообщения. Так кэш не продлевается всю ночь, пока вас нет.

**Панель `/cache-meter`:** рост контекста по ответам, итоги сессии, самые дорогие ответы, что принесли в контекст инструменты, самые большие результаты, повторно прочитанные файлы, журнал потерь кэша.

## Установка

В Claude Code:

```
/plugin install cache-meter --marketplace Dmitry7917/cache-meter
```

Из терминала:

```
claude plugin install cache-meter --marketplace Dmitry7917/cache-meter
```

## Настройки

Меняются в `/config`, строки cache-meter:

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Prompt cache TTL | `1h` | TTL кэша: `1h` на подписке, `5m` при оплате сверх лимита и в API |
| Context: yellow / orange / red from | 200 / 300 / 400 | Пороги цвета контекста, тысячи токенов |
| Warn before cache expiry | 5 | За сколько минут предупредить об истечении кэша, 0 выключает |
| Auto keepalive | вкл. | Автопродление кэша, один раз на каждое ваше сообщение |
| Auto keepalive before expiry | 2 | За сколько минут до истечения продлевать |
| Warn on tool results over | 15 | Порог большого результата инструмента, тысячи токенов, 0 выключает |
| Warn when a file is read this many times | 3 | После скольких чтений одного файла предупредить, 0 выключает |

## Ограничения

- Узнать TTL кэша из движка нельзя, он задаётся настройкой. Если сессия перейдёт на оплату сверх лимита и TTL станет 5m, таймер будет показывать больше, чем есть на самом деле. Выдаст это низкий hit после короткой паузы.
- Токены результатов инструментов оцениваются по длине текста, около 4 символов на токен. Для русского текста оценка занижена.
- Причину потери кэша мод угадывает: смену модели и effort видит точно, остальное — предположение.
- Учитывается основной диалог. Чтения и вызовы субагентов попадают в их собственный контекст и считаются только общей суммой токенов.

## Разработка

```
claude plugin validate .
claude plugin test .
```

Мод читается прямо из папки, если поставить его из локального маркетплейса (`claude plugin marketplace add <папка>`). После правки — `/reload-plugins`. Если поменялась `version` в `plugin.json`, сначала `claude plugin update cache-meter@dmitry-mods`, иначе Claude Code продолжит брать старую копию.
